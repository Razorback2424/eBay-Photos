FAQ

The practical questions
sellers ask first.

Do my photos upload to your server?

No. The current product positioning and landing-page copy both frame image processing as local in the browser, so this page keeps that claim only where it is explained directly and repeated consistently.

Which browsers work best?

Chrome, Edge, and Brave are the preferred path. Safari still works, but the current limitation is export behavior: Safari uses a ZIP download instead of direct folder write.

Who is this best for?

It is especially useful for higher-value singles where front, back, and corner details matter. It also helps any seller whose bottleneck is sorting and organizing a batch after the photos are taken.

What happens after I sign up?

You buy access on Gumroad, receive the license key immediately, enter it on the access page, and go straight into the workspace. The first in-app note then tells you how to photograph fronts, backs, and confirm pairings before export.

Do I need to install anything?

No install is required for the normal flow. The app is presented as a browser-based workspace where you upload scans, process them, and export listing assets.
